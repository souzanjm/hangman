# 🎮 Jogo da Forca em Python

Um jogo clássico da forca desenvolvido em Python, executado diretamente no terminal.

Este projeto simula a experiência tradicional do Hangman, onde o jogador deve adivinhar a palavra secreta letra por letra antes que suas vidas acabem.

---

## 🇺🇸 English Version

### 📌 About the Project

This is a simple terminal-based Hangman game built with Python.

The player must guess the hidden word one letter at a time. Each incorrect guess reduces the number of lives and gradually completes the hangman drawing.

---

### ✨ Features

✔ Random word selection  
✔ Input validation  
✔ Lives system  
✔ ASCII hangman visualization  
✔ Tracks used letters  
✔ Win / Lose conditions  

---

### 🚀 How It Works

- A random word is selected from a predefined list  
- The player guesses letters  
- Correct guesses reveal letters  
- Incorrect guesses reduce lives  
- The game ends when:
  - The word is completed ✅  
  - Lives reach zero ❌

## 🇧🇷 Versão em Português

### 📌 Sobre o Projeto

Este é um jogo da forca desenvolvido em Python para execução no terminal.

A jogadora deve adivinhar a palavra secreta letra por letra. A cada erro, uma vida é perdida e o desenho da forca é atualizado.

---

### ✨ Funcionalidades

✔ Seleção aleatória de palavras  
✔ Validação de entrada  
✔ Sistema de vidas  
✔ Visualização ASCII da forca  
✔ Controle de letras usadas  
✔ Condições de vitória e derrota  

---

### 🚀 Como Funciona

- Uma palavra aleatória é escolhida  
- A jogadora tenta adivinhar letras  
- Letras corretas são reveladas  
- Letras erradas reduzem vidas  
- O jogo termina quando:
  - A palavra é completada 🏆  
  - As vidas acabam 💀
